Weight file to Shell 64

A decimal weight file stores every coefficient. Shell 64 stores one reflex state per distinct data point, and a repeat only raises the count. The 63 shell checks, then math, then physics, all refine that same angle. They do not add another matrix.

Reflex variable state

Same job as a weight table, written as Tool Radian states. Each data point is a readable token — tool, kind, and an angle inside ±45° — not a decimal in a matrix. This uses the Shell 64 encoder from the LEATR model.
